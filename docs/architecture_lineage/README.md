## Claim Boundary

Allowed:

```text
engineering / R&D novelty inside this repo
custom combination of known ideas
stronger proof discipline than plain accuracy
local claims backed by gates and ablations
```

Not allowed yet:

```text
literature novelty claim
semantic grokking claim without proof gates
calling lookup, target_id, proof_rule_id, or label leak "understanding"
claiming full text generation solved from L1-L3 gates
```

## Current North Line

The architectural question is not:

```text
Can we imitate GPT with a smaller model?
```

It is:

```text
Can a small CPU-friendly wave/cell system learn a compact transferable
operator, reject near traps, survive ablation checks, and compile to a
fast runtime without lookup authority?
```
