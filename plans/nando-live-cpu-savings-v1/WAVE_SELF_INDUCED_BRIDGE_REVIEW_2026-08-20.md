### Confirmed self-induced baseline limitations

`crates/nando-core/src/wave/l3_self_induced_grokking.rs` explicitly calls itself
a tiny bounded step and is separate from the older semantic path. Source
inspection confirms:

```text
answer label
-> parse prefix and numeric slot
-> group observations by answer prefix
-> vote over modular answer-object delta
-> hand-built word/bigram/trigram feature field
-> majority/scoring thresholds
-> answer-prefix-based hidden-frame guess
```

Exact leakage-bearing operations include:

```text
builders.entry(answer.prefix.clone())
delta = answer.slot - object.slot mod modulus
hidden_frame_guess_from_answer_prefix(...)
```

The proof already reports `answer_surface_family_signal_used: true`, which is
honest. Consequently, its perfect bounded frame and answer accuracy cannot be
used as independent evidence that operator classes or frame identities were
self-formed without an operator-family channel.

The field `hand_written_cue_rules_used: false` is too broad. The implementation
contains generic but handwritten feature-selection rules in
`is_required_feature` and `is_relation_feature`, plus a handwritten slot-label
parser and contrastive corruption constructor. The defensible claim is:

```text
no family-specific handwritten operator rule was supplied
```

It is not:

```text
no handwritten cue or parsing rule exists
```

Likewise, `center_grokking_trace_observed` is currently an inequality over early
and final train/heldout accuracy. It does not measure abrupt circuit coherence,
phase locking, hysteresis, connected topology birth, or causal phase necessity.
It must remain a learning-trace metric, not a grokking verdict.

## 4. Truth Signal Versus Operator Identity

The new experiment must retain reality feedback while removing class identity.

Allowed teacher evidence after an action completes:

```text
pre-action observed state
opaque action occurrence
post-action observed state
independently verified typed consequence
source-neutral K0 relation/effect fragments
explicit censor or contradiction disposition
```

Forbidden before Dynamic Operator Field formation:

```text
answer or renderer family key
operator, frame, schema, role, template or generator ID
stable output prefix or output-class token
family-keyed map or cohort
caller-supplied complete operator topology
cross-surface global role identity
one trace containing the complete circuit
```

An output value may be observed as truth only through a typed consequence whose
surface spelling and local IDs are independently permuted. Any stable feature
that groups support rows by hidden operator before circuit formation is
operator-identity leakage and invalidates the experiment.
