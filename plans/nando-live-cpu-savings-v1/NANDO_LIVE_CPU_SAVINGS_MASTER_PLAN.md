traffic into independently verified CPU execution. Older status reports are

## 4. The V1 Census Error

Natural Vocabulary Census V1 performs:

```text
joined row
-> synthesize physical ResponsePrograms
-> collapse each program to top-level ResponseOperation
-> ask whether any protocol root is active
```

This is too coarse. For example, `function_call_from_roles` currently contains
many distinct physical programs. One represented protocol root can therefore
hide a new structural law inside the same top-level operation form.

Consequently:

```text
V1 NO_READY_FORM
```

means only:

```text
no readiness-PASS missing top-level ResponseOperation form was found
```

It does not mean that the natural structural frontier contains no undiscovered
law. V1 remains decode-compatible historical evidence and loses selection
authority.

## 5. Structural Frontier V2

V2 reuses the existing K1 substrate. It does not invent a second scheduler.

```text
joined natural rows
-> build_evidence_bindings
-> K1NaturalCohortCatalogV1
-> one V2 row per exact structural cohort tuple
-> readiness and novelty diagnostics
-> existing K1 queue/freeze/identifier
```

Physical programs are allowed only as post-cohort diagnostics. They may report
candidate count, exact replay, verifier compilation, and active protocol
coverage, but may not define or merge the cohort.

Every V2 report is content addressed:

```text
canonical report bytes
-> reports/<report_root>.json
-> file fsync
-> atomic latest.json rename
-> directory fsync
```

`latest.json` must decode to the newest successfully published report and have
the same root as its immutable report file. A stale or mismatched pointer is a
FAIL, not a dashboard warning.

## 6. Autonomous Lifecycle

```text
archive generation changes
-> rebuild structural frontier V2
-> publish immutable report
-> rebuild existing K1 queue
-> freeze at most one readiness-PASS candidate
-> existing identifier
```

Terminal states release the generation:

```text
PASS
ABSTAIN
ACQUISITION_FAIL
PROBE_EXHAUSTED
```

`PROBE_PENDING` is non-terminal. Candidate, version space, predictions,
budgets, and watermarks remain immutable.

An autonomous cycle may end with no freeze. In that case the report must name
one exact blocker with denominators, for example:

```text
capture_v2_rows_below_minimum
settled_rows_below_minimum
verified_rows_below_minimum
independent_lineages_below_minimum
source_neutral_binding_missing
candidate_generation_empty
all_exact_program_identities_already_certified
```

The broad blocker `all_supported_t1_protocol_modes_already_active` is not
sufficient to close a structural cohort.

## 7. Hard Authority Boundaries

Absolute vetoes:

- no synthetic or teacher-generated row may become natural evidence;
- no future response or terminal outcome may enter a pre-action prediction;
- no manual family mapping or handwritten operator assignment;
- no threshold weakening to force readiness;
- no local accept without independent verifier coverage;
- any false accept revokes the exact execution identity durably;
- no money claim without provider-billed evidence;
- old MS3 research remains closed while K1 runs independently;
- V2 reporting has no authority to mutate phase memory or activate a package.

## 11. Work Budget

To reduce model and server waste without lowering proof quality:

- batch independent reads, status checks, and test suites;
- filter logs to roots, counts, blockers, and errors before model ingestion;
- run heavy Rust builds and archive calculations only on the mini-PC;
- do not poll without a live process/session identifier;
- reuse fresh verified snapshots;
- keep generated caches outside source search and Git status;
- make one scoped behavior change per commit and deploy transactionally.

Fewer model/tool transitions are an efficiency improvement. They are not
scientific evidence, and Nando-routed model completions are not quality proof
unless independently verified.
