### 1.2 Teacher and outcome boundary

Learning uses the complete verified transition:

```text
X = pre-action observable state
A = observed teacher action
Y = independently verified post-action state

X -> A -> Y
```

The prohibition is not against learning from `A` or `Y`. The prohibition is
against using them to fabricate features that must have been observable in
`X`.

The mandatory protocol is:

```text
X
-> derive bounded topology T(X)
-> seal PreActionTopologyCommit
-> reveal A
-> reveal verified Y
-> learn which candidate law explains the transition
```

Teacher action supplies the target, post-action supplies causal feedback, and
the verifier establishes whether the consequence is real. Runtime
applicability and role grounding must remain derivable from `X` alone.

## 6. MS0-R: Historical Pre-Action Recovery


This step reads metadata, roots and byte availability. It does not extract

A historical row is recovery-eligible only when all are true:


