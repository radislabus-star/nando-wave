reveal, were sufficient and causally necessary for this bounded policy to

enumerating `8,659` complete programs on each of two generated tasks.

## 3. Invalid Attempts

The first failed run was not evidence against the hypothesis. Its feature
extractor used path-bearing file-entry equality where the frozen atom required
value equality. The repair changed only that implementation to compare content
hash and byte length.

The second run was not a valid PASS. It reached both confirm goals, but the
state ablation omitted feature column `5`, so control 6 did not remove all
current-state evidence. The repair completed the frozen mask. Fixtures,
features, model family, learned thresholds, beam width, and confirm bytes were
unchanged.

The right lesson is uncomfortable but productive: the experiment had strong
outer gates, yet the evaluator semantics still contained two ordinary coding
errors. The focused atom regression caught the first repair; future contracts
should generate ablation masks from named feature groups instead of duplicating
numeric indices in test code.

## 4. Strongest Alternative Explanation

A compact explicit heuristic over the same relation atoms may solve these two
tasks just as well or better. This experiment did not rule that out. It ruled
out the narrower null that complete enumeration was necessary for the frozen
learned policy and established that the learned parameters carried causal
ranking information under destructive ablations.

Therefore the honest statement is:

```text
learned hidden parameters compress bounded confirmatory search while
preserving exact execution in this generated environment
```

Not:

```text
Nanda has learned natural meaning or a universal planning representation
```

## 5. Architecture Improvement

The next slice should not add another passive benchmark. It should test whether
the agent can choose a safe experiment that resolves uncertainty more cheaply
than waiting or using a fixed probe list:

```text
frozen competing world models
-> enumerate only allowlisted reversible probes
-> predict each probe's distinguishing outcomes
-> rank expected information gain under exact cost and risk budgets
-> precommit one probe and all predictions
-> execute in a disposable sandbox
-> observe with a separate adapter
-> eliminate models using an independent verifier
-> freeze the updated model set
```

Required baselines are passive observation, stable-hash probe order, cheapest
probe first, and an oracle upper bound. Required negatives include an unsafe
high-information probe, a useless cheap probe, ambiguous outcomes, delayed
outcomes, and an unknown-effect action. The inquiry selector must never become
execution or certification authority.

## 6. Stop Rule

Do not begin natural K2 or language growth from this PASS alone. Advance only
if self-chosen inquiry beats every frozen non-learning probe baseline on a
sealed split while preserving exact safety, complete accounting, restart
parity, and authority false. A failure is a useful architecture boundary and
must not be repaired by widening the budget after reveal.
