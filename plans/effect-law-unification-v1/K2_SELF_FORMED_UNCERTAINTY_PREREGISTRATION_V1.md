
The predecessor's information-gain scorer, filesystem effect semantics,


This is a generated, finite, authority-free capability experiment. It is not
Natural K2, a learned general strategy, an open-ended ontology, a K1 law, a

## 2. Finite Question

The experiment asks one question:

> Given only incomplete before/action/after support observations, a finite
> source-neutral action vocabulary, and a frozen effect grammar, can Nanda
> construct the complete bounded set of semantically distinct world models
> that remain possible, mechanically derive a safe distinguishing probe, and
> use one independent observation to identify the hidden world model?

The question does not ask Nanda to invent the effect grammar, state language,
information objective, safety policy, or execution substrate.

## 5. Frozen Finite Language

Each case contains only public atoms derived from its support observations:

```text
opaque action IDs                 3 through 6
relative path atoms               at most 6
content atoms                     at most 3 exact byte strings
manifest entries                  at most 6
manifest bytes                    at most 98,304
protocol bytes                    at most 1,048,576
```

The hypothesis grammar is exactly:

```text
Effect ::= CopyFile(PathAtom, PathAtom)
         | RemoveFile(PathAtom)

WorldModel ::= total sorted map OpaqueActionId -> Effect
```

`CopyFile(p, p)` is invalid. Paths not present in the support-derived atom set,
multi-step programs, conditionals, wildcards, learned predicates, free strings,
and unknown opcodes are outside the language.

The finite state universe contains every manifest obtained by assigning each
path atom either `ABSENT` or exactly one public content atom. The maximum
unquotiented universe is therefore `(3 + 1)^6 = 4096` states. Invalid states
that exceed manifest budgets are rejected before semantic comparison and are
accounted separately.

## 6. Support Observations And Version Space

Each public support row contains only:

```text
case root
support sequence
pre-manifest
opaque action ID
typed post-manifest or typed failure
observation root
authority=false
```

It contains no effect label, model ID, private mapping, probe role, expected
version-space size, topology label, confirm outcome, or true-model root.

The learner must:

1. enumerate every syntactic total action-to-effect map in the frozen grammar;
2. execute each map against every support row using exact inherited semantics;
3. retain exactly maps that reproduce every support outcome;
4. reject the case if syntactic survivors exceed `256`;
5. compare survivors over the complete finite state universe and all actions;
6. quotient models with identical typed outcomes everywhere;
7. retain the lexicographically smallest model root as class representative;
8. emit every member, witness, class root, and denominator.

The learner may use pruning only if an unpruned reference enumerator and the
independent verifier reproduce the same complete syntactic and semantic sets.
Approximate search, beam search, sampling, a top-k list, or early selection is
not admitted.

Every confirm case must leave between `3` and `6` semantic classes before the
probe. Zero, one, more than six, or an omitted consistent class is terminal
scientific FAIL.

## 7. Mechanical Probe Enumeration

No probe list, role label, preferred action, or safety hint is supplied by the
generator. The probe enumerator receives only:

```text
public support root
finite state universe
opaque action vocabulary
self-formed semantic model set
frozen budgets
```

It enumerates every `(initial manifest, opaque action ID)` pair, predicts its
typed outcome under every semantic model, and forms a semantic probe class by:

```text
prediction partition
+ robust safety disposition
+ exact risk units
+ exact cost units
```

For each class it retains the smallest canonical probe root. Probes whose
predictions are identical under every model remain in the accounting but are
marked non-discriminating. The complete pre-quotient and post-quotient counts
must be emitted. No generator-owned name or array position survives into the
probe identity.

Eligibility is conjunctive and derived, never supplied:

```text
effect belongs to frozen grammar under every grammar possibility
all touched paths remain inside disposable tree
initial bytes required for exact rollback are present
observation is immediate and exact
risk <= 10 units
cost <= 10 units
action count == 1
manifest and protocol budgets pass
```

Safety is checked against the complete effect grammar, not merely the learned
survivor set, so an incomplete model set cannot make an unsafe probe eligible.

Risk and cost are deterministic functions of touched entries and bytes. The
same functions are separately implemented by selector and verifier. Stable
hash is never a safety fact.

## 8. Varied Confirm Topologies

The deterministic confirm generator produces twelve cases: three cases from
each of four frozen topology families. Identity, path, content, support order,
action order, private mapping, and case order vary by committed seed.

```text
family A   3 semantic models; includes 1/1/1 and 2/1 partitions
family B   4 semantic models; includes 1/1/1/1, 2/2, and 3/1 partitions
family C   5 semantic models; includes 1/1/1/1/1, 2/2/1, and 3/2 partitions
family D   6 semantic models; includes 1/1/1/1/1/1, 2/2/1/1, and 3/3 partitions
```

Across the four families:

```text

the lowest-risk probe is not always maximally discriminating
at least one family has two equal-information probes resolved by risk
at least one family has two equal-information/equal-risk probes resolved by cost
at least one unsafe probe has greater information than every eligible probe
the selected eligible probe has a singleton partition in every case
```

The learner and selector requests exclude topology-family labels and expected
partition shapes. The generator must emit exact denominators after reveal;
the verifier checks them against the committed deterministic generator.
