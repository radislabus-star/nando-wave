# Verified Causal AI Direction V1

Status: `ARCHITECTURAL DIRECTION / NOT AN AUTHORITY CLAIM`

Date: `2026-08-15`

## 1. Thesis

The bounded Law Lab result supports a concrete AI direction:

```text
observe state
-> choose or receive a safe opaque action
-> observe the exact state transition
-> induce a reusable action law
-> test the law on an unseen state
-> compose verified laws toward a goal
-> execute in isolation
-> verify the real outcome independently
-> retain only evidence-backed operators
```

This is not a text model replacement claim. It is a verified causal agent
architecture in which learned action laws, rather than generated prose, become
the durable unit of intelligence.

## 3. The Intended Intelligence Stack

```text
L1  verified action laws
    state + action -> state transition

L2  learned composition laws
    goal + available L1 laws -> causal program

L3  inquiry and strategy laws
    uncertainty + probe budget -> next safe experiment

L4  language-growth laws
    recurring failures and invariants -> new state predicates,
    role contracts, operators, and experiment languages
```

The stack is recursive only when a lower-level proved artifact becomes a
bounded input to the next level. A Rust branch, prepared DAG, hidden mapping,
fixture label, or LLM suggestion is not a learned law.

## 4. Runtime Ownership

```text
Observation adapter   establishes the world state without planner authority
Experiment scheduler chooses bounded safe probes without outcome leakage
Law learner           induces candidate transition laws from before/after rows
Causal memory         stores immutable laws, guards, costs, and proof roots
Planner               composes only available learned laws toward a frozen goal
Sandbox executor      performs the selected causal program without learning
Independent verifier reconstructs predictions and checks observed consequences
Admission             grants any later runtime authority; every prior stage is false
```

An LLM may translate language, propose hypotheses, or explain a result. It may
not certify a law, select hidden answers, or replace exact outcome verification.

## 5. Current Frontier

The explicit learned-world-model baseline is complete:

```text
hidden effects -> learned laws -> explicit composition -> exact action
```

The hidden-representation successor is also complete inside a bounded generated
environment:

```text
complete-search train decisions -> learned hidden ranking
-> sealed compositions -> bounded search -> exact action
```

Bounded model-guided active inquiry is now complete inside the same generated
filesystem environment:

```text
four supplied answer-blind world models
-> complete predicted consequence partitions
-> one safe reversible probe
-> independent observation
-> one surviving model in 8 / 8 sealed cases
```

The next finite question is uncertainty-set formation. From incomplete support
transitions, can Nanda induce several competing models, mechanically enumerate
allowlisted probes, and use the already proved scorer to close that uncertainty
with one independently observed intervention? Keeping the scorer fixed makes
model induction the only new mechanism.

Passing that successor still would not establish automatic language growth,
natural K2, open-ended planning, or production authority.

## 6. Best First Environment

The architecture should grow first in resettable domains with exact outcomes:

```text
filesystem transformations
Git operations
compiler and test workflows
CLI programs
SQL databases
structured document transformations
```

These environments permit safe interventions, deterministic replay, exact
state diffs, independent verification, and cheap counterexamples. Passive LLM
traffic remains useful product evidence, but it is a poor sole substrate for
learning causality because goals, alternatives, and interventions are usually
missing.

## 7. Main Research Risks

```text
representation ceiling       humans still define the observable predicates
combinatorial planning        complete enumeration stops scaling rapidly
partial observability         hidden state can make deterministic laws appear false
probe economics               informative interventions can be expensive or unsafe
goal grounding                a stated target may not encode the real objective
false abstraction            renamed fixtures can masquerade as new semantics
authority leakage             a proposer can accidentally become its own verifier
```

Composition, generated heldout representation transfer, and model-guided active
inquiry are now proved in their bounded scopes. The next architecture must form
its own competing uncertainty set, then attack partial observability and
learned state language. Natural and production authority remain downstream of
independent natural evidence.

## 8. Product Shape

The practical product is a verified action engine:

```text
unknown case -> expensive reasoning or safe experiment
repeated verified law -> immutable operator package
known applicable case -> deterministic CPU execution
uncertain or mismatched case -> ABSTAIN and fallback
counterexample -> next candidate generation
```

Its advantage is not merely lower token cost. It accumulates inspectable,
replayable, executable causal knowledge while retaining an explicit verifier
and rollback boundary.
