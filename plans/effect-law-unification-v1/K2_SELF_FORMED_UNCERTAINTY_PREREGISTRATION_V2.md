```text

  applied                         0
  read_entries                    1
  written_or_removed_entries      0
  overwritten_existing_entries   0
  removed_existing_entries       0
  overwritten_bytes              0

  written_or_removed_entries      1
  overwritten_existing_entries   0
  removed_existing_entries       1
  overwritten_bytes              0
  removed_bytes                  existing length
  touched_bytes                  removed_bytes
```

Exact units:

```text
risk_units = overwritten_existing_entries
           + removed_existing_entries
           + ceil((overwritten_bytes + removed_bytes) / 4096)

cost_units = 1
           + read_entries
           + written_or_removed_entries
           + ceil(touched_bytes / 4096)
```

`ceil(0 / 4096) = 0`; otherwise `ceil(n / 4096) = 1 + (n - 1) / 4096`.
Overflow, inconsistent lengths, or missing content bytes is VETO.

Probe risk and cost are the maxima over all sixteen grammar effects for the
selected opaque action, not only the four current model effects. This makes
accounting safe even if induction is incomplete. Limits remain:

```text

maximum cost units       10
action count              1
```

content bytes are snapshotted before dispatch, so every admitted mutation is
rollback-capable. Out-of-tree, symlink, special-file, unknown-opcode, ambiguous,
delayed, malformed, or over-budget probes are VETO controls and never execute.

Derived baseline bits are exact:

```text

dependency_hint    = initial manifest has at least two present entries
cleanup_hint       = robust risk_units <= 1
```

They are not inputs to the model-guided ranking tuple.
