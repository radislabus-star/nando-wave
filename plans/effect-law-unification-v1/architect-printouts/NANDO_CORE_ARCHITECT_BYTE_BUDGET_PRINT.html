От живого трафика
до проверенного CPU-оператора

Nando превращает завершённый опыт в компактные типизированные программы. Новый навык должен становиться данными и bytecode, а не новой веткой Rust. Сегодня production допускает три узких adaptive-оператора, но обычный live-трафик доказанно исполняет только write_stdin. Полное рождение нового circuit-attractor из multi-source fragments остаётся следующим научным рубежом, а не выданным результатом.

Точная формула машины: опыт создаёт evidence → learner сужает или рождает закон → crystallizer компилирует → Operator VM действует → verifier подтверждает → admission разрешает → CPU исполняет. Для сильного rich-claim learner должен родить новый связный circuit через межплоскостную фазовую когерентность, а не выбрать готовый шаблон.

Квантованный снимок закона

04 / REQUEST HOT PATH
Bounded execution, fail-closed

Один запрос, один структурный язык

Frozen evidence и live provider request обязаны сходиться в одном canonical structural view. Ни runtime adapter, ни learner adapter не имеют права изобретать отдельную relation-семантику.

  -> parse once
  -> CanonicalRuntimeRequestV3

  -> action-equivalence collapse

       exhausted      -> ABSTAIN
  -> Operator VM
  -> candidate output
  -> independent verifier repeats derivation
  -> verified match   -> local ACCEPT
