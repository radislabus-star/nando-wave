## Resulting Architecture

```text
append-only signed terminal history
-> deterministic diagnostic receipt
-> operator-blind family quotient
-> queue novelty rank
-> authority recomputation
-> immutable freeze
-> unchanged identifier and independent-future route
```

The critique rejects permanent family exclusion. The accepted mechanism is a
bounded ranking memory: it spends fresh attempts before repeated empty attempts
while retaining a complete fallback route.

## Residual Risk

The family key is intentionally coarser than an exact motif. It can demote an
untried motif that shares the same frozen structural world with four empty
motifs. This is acceptable only because demotion is reversible by ranking and
never exclusion. Production-copy shadow must demonstrate that at least one
fresh ready surface moves ahead while exhausted rows remain present behind it.

No scheduler policy can guarantee Law #2 exists in the current traffic. This
change removes repeated wasted experiments; it does not manufacture semantic
novelty.
